{# Shared design tokens and base type. Included by login, dashboard and entries. Inlined rather than served as a static file because mounting StaticFiles would mean editing main.py. The two webfonts are opt-in, because neither is used by every page. Set the flag before including this file: {% set heading_font = true %} Archivo — dashboard.html, entries.html {% set icons = true %} Tabler — dashboard.html only Opt in rather than opt out on purpose. A page that forgets `icons` renders empty boxes, which gets noticed within seconds; a page that forgets to opt *out* pays for the font silently and forever. The second is what happened here — login.html renders no icons and no Archivo glyphs (its only heading is the logo image), and was still fetching 211KB of Tabler stylesheet and opening two third-party connections on the app's first screen, usually on mobile data. #} {% if heading_font %} {# Archivo at 500, 600 and 700 — medium for tile titles and control labels, semibold for student names and the small caps captions, bold for headings. 600 joined when the name needed a real semibold: with only 500 and 700 on the wire a font-weight of 600 rounds *up* to 700, so every "semibold" caption in the app was quietly rendering bold. display=swap paints text in the fallback immediately and swaps when Archivo lands, rather than holding it invisible on a slow connection. The preconnects open the sockets early, since the stylesheet and the font file come from different hosts. #} {% endif %} {% if icons %} {# Tabler pinned to an exact version, not @latest: a CDN that silently moves under the app is the same failure mode as an unpinned requirements.txt. #} {% endif %}
